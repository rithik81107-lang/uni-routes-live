# Smart Waste Ai

App Prompt

Create a modern AI-powered college transportation app for students.

The app should allow students to view college bus routes, bus numbers, stops, and expected arrival times. Show the buses on a live map and allow students to select their bus stop to see the estimated arrival time.

Include these main features:

 Student login/signup

 List of college buses

 Live bus location

 Bus route and stop details

 Estimated arrival time

 Notifications for bus delays or route changes

 Search for a bus stop

 Emergency/contact button

 Simple dashboard showing the student's selected bus and next arrival

Use a clean, simple, student-friendly UI with easy navigation. Make it responsive for both mobile and desktop. Add sample bus and route data so the app can be tested without a real GPS system.
